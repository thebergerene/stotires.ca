# delivery_app Source Tree

## Getting Started

### 1. Backend Engine Setup
```bash
npm init -y
npm install express pg crypto
# Update database configuration details inside your server.js profile layout
node server.js
```

### 2. React Native Frontend Applications Setup
```bash
# Initialize project environment frames
npx create-expo-app delivery-frontend
cd delivery-frontend
npx expo install expo-camera expo-location

# Drop CustomerApp.js and DriverDashboard.js into project components mapping structures
```
